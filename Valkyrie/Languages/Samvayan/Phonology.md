#conlang #samvay #valkyrie-world  #samvayan #worldbuilding 
Samvayan phonology is somewhat similar to the real-life language Sanskrit, with a set of basic consonants that can be mutated in various ways.
# Consonants
The consonant inventory of Samvayan has five places of articulation: labial, dental, retroflex, palatal, and velar. While there are *sensu stricto* only voiceless plosives, voiced plosives, voiceless fricatives, voiced nasals, and voiced approximants, *de facto* there are many mutations that can be applied to various sets of consonants.

|             | -   | Labial | Dental | Cerebral | Palatal   | Velar |
| ----------- | --- | ------ | ------ | -------- | --------- | ----- |
| Plosive     | -   | p b    | t d    | ʈ ɖ      | (t͡ɕ d͡ʑ) | k g   |
| Fricative   | -   | ɸ      | s      | ʂ        | ɕ         | x     |
| Nasal       | -   | m      | n      |          | ɲ         | ŋ     |
| Approximant | -   | β      | l      | ɻ        |           |       |
While this table could look neater, as the missing cells represent sounds that do exist in Samvayan, this would require some serious concessions:
* The cerebral nasal /ɳ/ and the velar approximant /ɰ/ are both heavily restricted.
	* /ɳ/ is only permissible intervocalically or at the beginning of a word and becomes palatal /ɲ/ elsewhere.
	* The palatal and velar approximants /j ɰ/ only appear epenthetically and intervocalically, and in both cases can be treated as the non-syllabic allophone of /i u/. Notably, this is not true of the other approximants, which can also begin a word or be a coda.
* All sonorants can be syllabic.
	* Syllabic nasals are better described as syllabic approximants, as closure is incomplete for them.
	* These originate from lax vowels that have since been either nuked or merged with /e a o/.
	* Other notes can be found in the Vowels section.
* All approximants can be nasalized.
	* Historically, these are the result of the sequences /NP NB/ rather than /NS NZ/; while /NS NZ/ *did* nasalize, those nasals have since died in modern Samvayan.
# Vowels
As stated above, all sonorants can be syllabic. Thus, the number of true vowels in Samvayan is surprisingly low.
```vowel-chart
layout formant
add [i]
add [ɪ] "(j)"
add [ʊ] "(ɰ)"
add [ʏ] "(β)"
add [u]
add [e]
add [ɘ] "(l)"
add [o]
add [ɤ] "(ɻ)"
add [a]
```
Often, syllabic approximants are rendered, at least phonetically, using the equivalent vowel phones from the table above: /β ɻ l/ \[ʏ ɤ˞ ɘ]; syllabic /j ɰ/ is identical to /i u/. Syllabic /l/ sometimes labializes to distinguish from /e/, but this often results in /o/ rather than /e/.
Before a nasal or nasalized approximant, vowels will both laxen and nasalize.
# Phonotactics
## Syllable structure
Samvayan has a syllable structure of CCVC. However, codas can only be sonorant, unless they are at the end of the morpheme; morpheme-final stops become fricatives when affixed onto. Initials have to either consist of a sibilant fricative followed by a plosive, or a plosive followed by either its homorganic fricative or /x/. Usually, the latter becomes an aspirated plosive if the fricative is non-sibilant and the plosive is unvoiced.
This is also why /t͜ɕ d͜ʑ/ are marginally phonemic, as they could be considered clusters, /tɕ dʑ/, instead.
