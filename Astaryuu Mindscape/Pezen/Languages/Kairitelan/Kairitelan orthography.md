Kairitelan may be either written using the Latin alphabet or the native Kairitelan abugida.

# Romanization

Kairitelan phonemes are written as seen in the IPA, with the following exceptions:

- /ɲ/ is written as nh, except when before \<c> or \<j>, in which case the h is dropped
- /ʎ/ is written as lh, except when before \<c> or \<j>, in which case the h is dropped
- /ŋ/ is written as ng
- /ɟ/ is written as j
- /ɕ/ is written as sh
- /ʑ/ is written as zh
- /j/ is written as y in the onset (and in i-on-glide diphthongs) and i in the coda (in i-off-glide diphthongs)
- /w/ is written as w in the onset and u in the coda (in diphthongs)
- /x/ is written as kh
- /ɣ/ is written as gh
- /ɯ/ is written as u, unless it is followed by a coda sonorant, in which case it is written as y
- /:/ is written as an acute accent
- Open-mid vowels are written with the adjacent monophthong's grapheme, plus an acute accent for long vowels or a tilde accent for nasalized vowels
- /ɛi ɔu/ are written as í ú

What type of pitch accent a word uses goes unwritten in blocks of text.
